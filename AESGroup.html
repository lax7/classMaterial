Group Exercises (Additive Group)

A set S under addition is an Abelian Group if it satisfies these 5 conditions:

1. Closure: If a, b ∈ S, then (a + b) ∈ S.
2. Associativity: (a + b) + c = a + (b + c).
3. Identity: There is an e ∈ S where a + e = a.
4. Inverse: For every a, there is a -a ∈ S where a + (-a) = e.
5. Commutativity: a + b = b + a.

1. Even Integers {..., -4, -2, 0, 2, 4, ...}

ConditionStatusReasoning
ClosurePassedThe sum of two even numbers is always even.
AssociativityPassedInteger addition is associative.
IdentityPassed0 is an even integer (2 × 0).
InversePassedIf x is even, -x is also even.
CommutativityPasseda + b always equals b + a for integers.
RESULT: This IS an Abelian Group.

2. Natural Numbers {0, 1, 2, 3, ...}

ConditionStatusReasoning
ClosurePassedSum of two positive integers is always positive.
AssociativityPassedStandard property of addition.
IdentityPassed0 is included in the set.
InverseFailedFor 3, the inverse is -3, which is NOT in the set.
CommutativityPassed1 + 2 = 2 + 1.
RESULT: This is NOT a Group (Inverse missing).

3. Odd Integers {..., -3, -1, 1, 3, ...}

ConditionStatusReasoning
ClosureFailed1 + 3 = 4 (Even). Result is not in the set.
AssociativityPassedAddition is associative.
IdentityFailed0 is not an odd number.
InverseFailedNo identity exists in the set.
CommutativityPassed1 + 3 = 3 + 1.
RESULT: This is NOT a Group.

4. Integers Modulo 4 {0, 1, 2, 3}

Operation: Addition Modulo 4

ConditionStatusReasoning
ClosurePassedAll sums mod 4 result in {0,1,2,3}.
AssociativityPassedModular addition is associative.
IdentityPassed0 is the identity.
InversePassedEach element has an inverse (e.g., 1+3=0).
CommutativityPassedThe Cayley table is symmetric across the diagonal.
RESULT: This is an Abelian Group.
