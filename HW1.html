Task 2: Frequency Analysis Attack

[ 15 points total ]

💡 Terminal Tip: Background Processes

Adding the & symbol at the end of your command tells the computer to run the process in the background.

Example: If you type gedit plaintext.txt &, the text editor opens, but your terminal stays active so you can keep executing commands.

Instructions: Download Labsetup.zip inside your SEED VM. You are provided a ciphertext encrypted with a monoalphabetic cipher. Your goal is to recover the original plaintext using frequency analysis.

🛠️ Setting Up the Shared Folder

  1. In VirtualBox, select the SEED VM.
  2. Go to Settings > Shared Folders.
  3. Add a folder, select your path, and check Auto-mount.
  4. In the SEED VM Terminal, run:
    sudo adduser seed vboxsf
  5. Restart the VM.
