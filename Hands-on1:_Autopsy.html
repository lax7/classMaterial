Part 1: Setting Up & Organizing Case Files

Estimated Time: 1-2 hours

1. Download and Install Software

Autopsy: Go to autopsy.com and click the "Download" button. Follow the installation instructions for the 64-bit version.
HxD Hex Editor: Download from mh-nexus.de. This provides a more powerful hex editor that integrates directly with Autopsy's interface.

2. Organize Case Data Directory

IMPORTANT: Do NOT save suspect data on your forensic workstation's C: drive. This avoids cross-contamination and performance issues.
Create a dedicated Cases folder on a separate drive (D:, E:, or external HDD/USB).
Create a specific folder for this case using the naming convention: [Case Number]-[Investigation Type]-[Investigator Initials] (Example: 001-Hacking-LNK).
Inside your Case Folder, create these sub-folders:
  • docs (for case notes and documentation)
  • images (for storing forensic copies/images of data)
  • temp (for temporary extraction files)
  • autopsy (for the Autopsy case database)
  • reports (for final exported findings)

3. Case Documentation Initial Step

In the docs folder, create [Case Number]-docs.txt. Open it in Notepad and press F5 to insert a timestamp. Note: "Case started by [Your Name]".

Part 2: Starting a New Case in Autopsy

Launch Autopsy and select "New Case" from the splash screen.
Case Name: Enter the name of your case folder (e.g., 001-H-XX).
Base Directory: Click Browse, navigate to your case folder, and select the autopsy sub-folder as the destination.
Case Type: Select "Single User" and click Next.
Organizations: Manage Organizations > New > enter "Student Lab". Click OK and select it from the dropdown.
Documentation: Copy the full path to the Autopsy case data directory and paste it into your docs.txt file with a timestamp.

Part 3: Adding a Data Source

Host Name: Enter the unique exhibit identifier (e.g., Exhibit001).
Select Source Type: Select "Disk Image or VM File" and browse to your SuspectData.dd file in the images folder.
Settings: Ensure Time Zone is GMT +00:00 - UTC and Sector Size is Auto Detect.

Integrity Verification (Hash Values)

Paste these hash values into the "MD5" and "SHA-256" fields to ensure data hasn't been tampered with:
MD5: 26D81C6C26D68C9F7575306B9A89A986
SHA-256: F39F8090C8B1E919C157EE45929A2624D04C1C40C3ED84C511B45F540E9A98E7

Part 4: Configure Ingest Modules

These automated processes extract artifacts while you work.

Mandatory Modules: Keep checked: Recent Activity, Hash Lookup (ensure Calculate MD5 is selected), File Type Identification, Extension Mismatch Detector, Embedded File Extractor, Picture Analyzer.
Keyword Search: Click the module and ensure "Enable Optical Character Recognition (OCR)" is checked to find text inside images.
PhotoRec Carver: Ensure this is checked. In settings, verify "Carve everything" is selected to recover deleted data.
Performance Optimization: Uncheck the following to save time: Encryption Detection, Virtual Machine Extractor, ALEAPP, iLEAPP, Plaso, YARA, and Android Analyzer.

Part 5: Initial Analysis Workflow

1. Navigation and Viewing

In the left "Tree" pane, expand Data Sources > Exhibit001 > suspectdata.dd.
Select a file and toggle between bottom pane views: Application (standard view), Hex (HxD-style raw data), Text (Strings), and Metadata.

2. Forensic Search & Tagging

Click Tools > Keyword Search. Search for cat using "Exact Match". Note the results.
Repeat search for cat using "Substring Match" and observe how many more items are found (e.g., words like "catapult" or "category").
Tagging: Right-click an interesting file > Add File Tag. Tag several files as Bookmark, Notable, or Follow Up. Review these later under the "Tags" section in the left pane.

Part 6: Generating a Findings Report

Click Tools > Generate Report and choose "HTML Report". Click Next.
Select Data: Choose "Specific Tagged Results". Check Bookmarks and Notable. Uncheck "Follow Up" for the final version.
Review: Click the link to open the report in your browser and verify your tagged files and metadata are visible.
Cleanup: Move the generated report folder from the autopsy directory to your reports folder. Rename it to Supporting_Evidence_Report.

Investigation Concluded

Environment setup, data processing, analysis, and evidence reporting are now complete.
