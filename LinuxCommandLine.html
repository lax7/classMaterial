4. Inode & File System

What is an inode?
Inode is an ID of a file or folder. It’s a unique number. Inode is a data structure of a file. You store your information in a file, and the operating system stores the information/metadata about a file in an inode. The inode points to the content of a file.

Accessing a file: File name ⇒ Inode ID ⇒ File Content.

Commands:

  • ls -ia : Show inode numbers of files.
  • df -i : Show disk free information for inodes.
  • ls / : Show linux file system from root.
  • pwd : Print working directory.

6. Linux File Permission (Chmod)

Permissions are calculated using Read (4), Write (2), and Execute (1).

Pro Tip: You can also use symbolic mode directly, for example: chmod ugo+r filename to give everyone read access.
