🎓 Reasoning: How the Mask works

The One-Time Pad is malleable because bitwise XOR is used. An attacker can change the output without knowing the key using the XOR Delta formula:

Mask (M) = Original Char ⊕ Target Char

Step-by-Step for '1' to '5':

  • Original '1' is Hex 31 (Binary 0011 0001)
  • Target '5' is Hex 35 (Binary 0011 0101)
  • XORing them gives 04 (Binary 0000 0100)

When the bank decrypts: (Ciphertext ⊕ Mask) ⊕ Key is calculated. The Key cancels out, and the original character is transformed by the mask into the target character. No key required.

Conclusion: OTP is "perfectly secret" but has zero "integrity." Without a Message Authentication Code (MAC), the message is malleable.
