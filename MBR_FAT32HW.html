Tracing a Fragmented File in the FAT
The File Allocation Table (FAT) stores a chain of cluster entries for each file. Each entry points to the next cluster used by the file or contains a special end-of-chain marker. In FAT32 each FAT entry is 4 bytes wide, this is where the '32' in FAT32 comes from, referring to the 32-bit (4 byte) size. This means to find the FAT entry for any given cluster you multiply the cluster number by 4 to get the byte offset into the FAT table.
