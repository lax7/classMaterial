Digital Forensics: Data Acquisition Tracker

Use this interactive checklist to manage your forensic tasks. Ensure you record a screenshot for each step indicated for your Word document submission.

1. Environment Setup

Launch SIFT Workstation: Start your VM and open the terminal.
Disk Identification: Identify your physical USB path.
sudo fdisk -l
Verify Mount: Check the USB connection.
mount
📸 RECORD SCREENSHOT: Mount output highlighting the USB device
📸 RECORD SCREENSHOT: fdisk output showing device path (e.g., /dev/sdb1)

2. Physical Drive Hashing & Disk Copying (USB)

Physical Drive Integrity Check: Calculate hashes of the raw USB device.
sudo md5sum /dev/sdb1 > usbHash1.txt
sudo sha256sum /dev/sdb1 > usbHash2.txt
Note: This will take time. Duration increases with the size of the USB drive.
📸 RECORD SCREENSHOT: MD5 and SHA256 results for the physical drive
Copy Operations: Use dd and dcfldd for file duplication.
dd if=[source] of=copy1.dd
dcfldd if=[source] of=copy2.dd
📸 RECORD SCREENSHOT: Execution of dd and dcfldd commands and output of ls -l
Verify File Integrity: Store hashes in log files.
md5sum copy1.dd > copyHash1M.txt
sha256sum copy1.dd > copyHash1S.txt
md5sum copy2.dd > copyHash2M.txt
sha256sum copy2.dd > copyHash2S.txt
📸 RECORD SCREENSHOT: Logs showing copyHash1M.txt same as copyHash2M.txt. Also, this hash should be same as usbHash1.txt

3. Drive Imaging

Zero Fill: Create zero.dd.
dd if=/dev/zero of=zero.dd bs=512 count=1

4. Extra Credit

Segmented Acquisition: 30MB splits.
dcfldd if=/dev/[device] of=usb_split.dd split=30M hash=md5
cat usb_split.dd.* | md5sum
📸 RECORD SCREENSHOT: Segmented files and final piped hash
