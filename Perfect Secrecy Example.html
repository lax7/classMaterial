Information Leak in Shift Cipher (Not perfeclty secure)

Message Space ℳ = {ATTACK, REMARK}.
Key Space 𝒦 = {0, 1, ..., 25}.
Attacker observes c = CVVBDM.

Hypothesis: M = ATTACK

A + 2 = C (k=2)
T + 2 = V (k=2)
K + 2 = M (k=2)

Result: Consistent! A single constant shift k=2 maps the message to the ciphertext.

Hypothesis: M = REMARK

R + 11 = C (k=11)
E + 17 = V (k=17)

Result: Impossible! In a Shift Cipher, all letters must be shifted by the same constant k.

Since Posterior probability is not equal to prior probability, it is NOT perfectly secret. The ciphertext provide leaked information about the plaintext.
