Using ExifTool for Metadata Analysis

What is ExifTool?

EXIFTOOL is a free and open-source command-line application used to read, write and manipulate metadata of various file types, including images, videos, PDFs and documents. It supports a wide range of metadata formats such as EXIF, IPTC, XMP, ID3, and many others.

Developed by Phil Harvey, ExifTool is widely used in fields such as:

  • Digital Forensics
  • Cybersecurity
  • Photography
  • eDiscovery
  • Reverse Engineering

Case Scenario

You are a digital forensics investigator working with ERAU campus police to investigate a cyberbullying case. A student, Ernie, has been receiving threatening messages and having doctored photos posted to a fake social media account impersonating them.

Campus police has seized multiple files from the fake account before they were taken down. Your task is to analyze the metadata in these files to help identify the source of the cyberbullying and build a timeline of events.

Investigation Tasks

Task 1: Basic Metadata Extraction

Extract and document the complete metadata for one image from the evidence files.

Commands:

# Extract all metadata from a single image
exiftool [Source File]

# Extract specific metadata tags
exiftool -Make -Model -Software [Source File]

# Export all metadata organized by tag group to a text File
exiftool -a -G1 -s [Source File] > [OutputFile].txt

What to document:

  • Camera make and model [2 points]
  • Software used to create/edit the image [2 points]
  • Image dimensions [2 points]

Task 2: Timeline Analysis

Construct a comprehensive timeline of events.

Commands:

# Extract all metadata relating to date/time
exiftool -time:all *.jpg

# Check for any discrepancies in the date
exiftool -CreateData -ModifyDate [Source File]

What to document:

  • Create a timeline of events for when the images were created and modified [2 points]
  • Any discrepancies between creation and modification dates [2 points]

Task 3: Detecting Manipulated Images

Identify which files have been manipulated and what software was used.

Commands:

# Check for any editing softwares used
exiftool -Software -ProcessingSoftware [Source File]

# Look for editing markers
exiftool -History -Comment [Source File]

What to document:

  • Which files show signs of manipulation? [2 points]
  • What software was used to manipulate the images? [2 points]

Task 4: GPS/Location Data

Extract and analyze GPS coordinates to determine locations.

Commands:

# Extract GPS data from all files
exiftool -GPS:all *.jpg

# Get decimal GPS coordinates
exiftool -n -GPS:GPSLatitude -GPS:GPSLongitude [Source File]

What to document:

  • Which photos contain GPS data? [2 points]
  • What are the exact coordinates? [2 points]

Report Conclusion

[5 points]

Create a comprehensive report, answer: What have you found from the investigation? What had happened? Provide your conclusion based on the evidence following these 5 points:

  • 1. Identification: Which device(s) were used to capture the original images?
  • 2. Manipulation: Which specific files were doctored, and what software confirms this?
  • 3. Timeline: Reconstruct the sequence of events—when were the photos taken vs. when were they edited?
  • 4. Attribution: Based on GPS and software tags, where were the photos edited?
  • 5. Verdict: Summarize your final forensic opinion on the source of the cyberbullying.
