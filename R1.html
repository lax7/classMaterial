Chapter 2: Perfectly-Secret Encryption(Read Upto Def 2.1)

Key Takeaways

Information-Theoretic Security: Perfect secrecy doesn't depend on an adversary's computing power; it depends on the lack of information in the ciphertext.
Probabilistic Nature: Modern encryption schemes often use randomness (probabilistic algorithms) to ensure the same message looks different every time.
The Core Requirement: For a scheme to be perfectly secret, observing a ciphertext must provide zero new information about the plaintext.
Indistinguishability: If an adversary cannot distinguish which of two messages was encrypted, the scheme is secure against an eavesdropper.

1. Definitions and Basic Properties

An encryption scheme is defined by three fundamental algorithms:

  • Gen: A probabilistic algorithm that outputs a key k chosen from a key space K.
  • Enc: Takes a key k and a message m to produce a ciphertext c. Written as c ← Enck(m) when Enc is probabilistic and c:=Enck(m) when Enc is deterministic.
  • Dec: Takes key k and ciphertext c to recover message m.

We assume schemes are perfectly correct, meaning that decrypting a valid ciphertext always returns the original message (Deck(Enck(m)) = m) with probability 1.

2. Defining Perfect Secrecy

Intuitively, an adversary who observes a ciphertext should learn absolutely nothing about the underlying message. Their "a posteriori" knowledge (after seeing the ciphertext) should be identical to their "a priori" knowledge (before seeing it).

DEFINITION 2.1: An encryption scheme is perfectly secret if for every distribution over M, every message m, and every ciphertext c:
Pr[M = m | C = c] = Pr[M = m]

3. Perfect Indistinguishability

Lemma 2.3 provides an equivalent formulation: the distribution of ciphertexts must be independent of the plaintext. This is often called Perfect Indistinguishability.

For every m₀, m₁ and every c:

Pr[C = c | M = m₀] = Pr[C = c | M = m₁]

4. Adversarial Indistinguishability (Experiment PrivKeav)

We define a formal experiment, PrivKeav, to test security:

  1. Adversary A chooses two messages m₀, m₁.
  2. A random key k is generated and a random bit b ∈ {0,1} is chosen.
  3. The ciphertext c ← Enck(mb) is given to A.
  4. A outputs a guess b'. The experiment is successful if b' = b.
DEFINITION 2.4: An encryption scheme is perfectly secret if for every adversary A:
Pr[PrivKeav{A,Π} = 1] = 1/2
