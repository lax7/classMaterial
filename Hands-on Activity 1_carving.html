2. Conversion Examples

Binary to Decimal

To convert, multiply each digit by 2 raised to the power of its position (starting at 0 from the right).

Binary: 1011
(1 × 2³) + (0 × 2²) + (1 × 2¹) + (1 × 2⁰)
8 + 0 + 2 + 1 = 11

Hexadecimal to Binary

Each Hex digit represents exactly 4 bits (a "nibble").

Hex: A3
A = 1010
3 = 0011
Result: 10100011

3. Text and Characters

Computers only understand numbers, so we use "encoding" to map numbers to letters.

  • ASCII: Uses 7 bits. Covers English letters, numbers, and basic symbols.
  • UTF-8: A variable-width encoding that can represent every character in the world. It is backwards compatible with ASCII.
  • Control Characters: Special codes like 0A (Hex) which represents a Newline (\n).

4. Digital Timestamps (Epochs)

Systems measure time as the number of seconds (or microseconds) passed since a specific "starting point" called an Epoch.

  • Unix Epoch: January 1, 1970. (Standard for Linux and Web).
  • Mac Epoch (Cocoa): January 1, 2001. (31-year difference from Unix).
  • WebKit/Chrome: Microseconds since January 1, 1601.

File carving is a process used in computer forensics to extract data from a disk drive or other storage device without the assistance of the file system that originally created the file.

Automated Recovery Tool: PhotoRec

While this lab focuses on manual carving, automated tools like PhotoRec are often used in professional investigations.

  • PhotoRec is open source recovery software designed to recover lost files, including video, documents, and archives from hard disks, CD-ROMs, and lost pictures from digital camera memory.
  • PhotoRec ignores the file system and goes after the underlying data, so it will still work even if your media's file system has been severely damaged or reformatted.
  • It is available for the Windows, Linux, and MAC operating systems.
