Hands-on Activity: File Carving without a Carving Tool

What is File Carving?
File carving is a process used in computer forensics to extract data from a disk drive or other storage device without the assistance of the file system that originally created the file.

Task 2: Extract a JPG from a Word Document

The goal is to extract a jpg image from an unknown file (assuming the unknown file is a word file). You will extract the image from clusters in HxD.

Step 1: Locate the Image Data

  • Open the unknown document (Word document) in HxD.
  • Go to Search > Find and enter the magic number (header) for jpeg. Copy the start offset.
  • Search for the File Trailer offset by searching for the hex value: FFD9.
  • Similarly search for the File Trailer offset by searching for the hex value: FFD9.

Step 2: Select and Copy

  • Go to Edit and select Select Block.
  • Enter the Start Offset and the End Offset you recorded in the previous step.
  • Right-click and Copy the highlighted block.

Step 3: Save the Recovered File

  • Go to File > New; this will open a tab titled "Untitled".
  • Paste the copied block into the new file.
  • Go to File > Save As and save the file as carved.jpg.

Automated Recovery Tool: PhotoRec

While this lab focuses on manual carving, automated tools like PhotoRec are often used in professional investigations.

  • PhotoRec is open source recovery software designed to recover lost files, including video, documents, and archives from hard disks, CD-ROMs, and lost pictures from digital camera memory.
  • PhotoRec ignores the file system and goes after the underlying data, so it will still work even if your media's file system has been severely damaged or reformatted.
  • It is available for the Windows, Linux, and MAC operating systems.
