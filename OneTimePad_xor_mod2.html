The One-Time Pad Challenge



🚨 Unconditional Security/Perfect Secrecy (OTP)

Alice encrypts 10,000 bits using a One-Time Pad. Remember, OTP is perfectly secure, which means an attacker with infinite computational resources cannot break it.

We can assume that the attacker has 210,000 computers and each computer can check exactly one key. This will take only one time step.

The Scale of Impossible:
There is no way 210,000 computers can exist. It is estimated that there are "only" about 2266 atoms in the known universe.

Question: Can the attacker find Alice's message?
