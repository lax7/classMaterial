2. The Ring Example

Set: All Integers (..., -1, 0, 1, ...)

The set of all Integers is a Ring because you can add and multiply, but you cannot always divide.

WHAT WORKS (Success)

2 * (3 + 4) = (2 * 3) + (2 * 4).
Distributive property is satisfied!

WHAT FAILS (No Inverse)

Try to find "x" such that: 2 * x = 1.
In this set, there is no integer solution. Division is broken!
